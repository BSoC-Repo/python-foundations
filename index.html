Part 1: First Steps

This part assumes no previous programming experience. You will write and run your first Python programs, store information in variables, ask the user for input and make your programs take decisions.

Learning objectives

By the end of this part, you will be able to:

  1. Write and run a Python program in VS Code that displays output using print().
  2. Use variables of the correct data type (str, int, float, bool), read input with input(), convert it, and display results with f-strings.
  3. Write if, elif and else statements, using comparison and logical operators, so that a program makes decisions.

Why this matters in industry

Python is everywhere

Python is one of the most widely used languages in the world. It powers web back ends, data analysis, automation scripts, testing tools and machine learning.

Every program uses these basics

However large a system is, it is built from the ideas in this part: storing values, reading input, showing output and making decisions.

Decisions drive software

Should this user be allowed to log in? Is the server overloaded? Has the order been paid for? Each question becomes an if statement in code.

Summary and self-assessment

Key points

  • A program runs from top to bottom. print() displays output in the terminal.
  • A variable stores a value. = means "store", not "equals".
  • The four basic data types are str, int, float and bool.
  • input() always returns a string; convert it with int() or float() before doing maths.
  • f-strings place values inside text: f"Hello, {name}".
  • if, elif and else choose which code runs. Only the first true branch runs, so order matters.
  • and needs both conditions to be true; or needs at least one; not reverses a condition.

Key words

Program
A set of instructions that a computer follows.
Function
A named instruction that does a job, such as print() or input(). You call it by writing its name followed by round brackets.
Variable
A name that stores a value, which can change while the program runs.
Constant
A variable whose value should not change, written in capital letters.
Data type
The kind of value: text (str), whole number (int), decimal number (float) or True/False (bool).
Condition
An expression that is either True or False, such as cpu_usage >= 90.
Selection
Choosing which code runs, using if, elif and else.
Indentation
The four spaces at the start of a line that show it belongs to the line above that ends with a colon.
Syntax error
A mistake in the grammar of the code. The program cannot start.
Logic error
Valid code that does the wrong thing. The program runs but gives incorrect results.

A function is a named block of code. You have already used built-in functions such as print() and len(). Now you will write your own.

You define a function with def, a name, round brackets and a colon. The indented lines underneath are its body. Defining a function does not run it: the body runs only when you call the function by writing its name followed by brackets.

The names in the brackets of the def line are parameters: variables that receive values when the function is called. The values you pass in a call are arguments. A parameter can have a default value, used when no argument is given.

3b. Return values and scope

Part 1: sending a value back with return

return ends the function and sends a value back to the line that called it. That line can then store the value, print it, use it in a calculation or test it in an if statement.

This is the key difference from print(): printing only displays a value on screen, and the rest of the program cannot use it. A function with no return statement gives back the special value None, meaning "nothing".

A variable created inside a function is local: it exists only while that function runs, and the rest of the program cannot see it. A variable created outside any function is global, and functions can read it.

A docstring is a string in triple quotation marks on the first line of a function's body. It says what the function does. VS Code shows it when you hover over a call to the function, so other people can use your code without reading it all.

Summary and self-assessment

Key points

  • def name(parameters): defines a function. It runs only when called with name(arguments).
  • Parameters can have default values, and keyword arguments name the parameter they fill.
  • return ends the function and sends a value back. Without it, a function returns None.
  • print only displays a value; return lets the rest of the program use it.
  • Variables created inside a function are local. Pass values in with parameters and out with return.
  • A docstring describes what a function does. assert tests check that it does it, including edge cases and boundaries.
  • The debugger pauses at a breakpoint so you can step through code line by line and watch variables change. Step Into goes inside a function; Step Over runs it in one go.

Key words

Function
A named, reusable block of code that runs when it is called.
Parameter
A variable in a function's definition that receives a value when the function is called.
Argument
The actual value passed to a function when it is called.
Return value
The value a function sends back to the line that called it.
Scope
Where a variable can be used. Local variables exist only inside their function; global variables exist everywhere.
Docstring
A string in triple quotation marks at the start of a function, describing what it does.
Test
Code that checks a function gives the expected result, such as an assert statement.
Refactor
Improve the structure of code without changing what it does.
Debugger
A tool that pauses a running program so you can step through it and inspect its variables.
Breakpoint
A marked line where the debugger pauses the program, before that line runs.

3a. Creating and using a dictionary

A dictionary stores key-value pairs. Each key is a name, usually a string, and it maps to a value, which can be any data type. You write a dictionary with curly brackets, putting a colon between each key and its value.

You look up a value with its key in square brackets, such as config["port"]. If the key does not exist, Python stops with a KeyError. The get() method is the safe alternative: it returns None, or a default you choose, when a key is missing.

Keys are unique: assigning to a key that already exists replaces its value, and assigning to a new key adds a pair. in checks whether a key exists.

Key points

  • A dictionary maps unique keys to values: {"port": 8080}.
  • d[key] looks a value up and raises a KeyError if it is missing; d.get(key, default) never crashes.

  • Looping over a dictionary gives its keys. Use items() to get keys and values together.

  • A list of dictionaries holds records, the same shape as JSON from a web API.
  • Dictionaries are mutable: a function can change one that it is given.

Key words

Dictionary
A collection of key-value pairs, written in curly brackets.
Key
The unique name used to look up a value, such as "port".
Value
The data stored under a key, which can be any type, including a list or another dictionary.
KeyError
The error raised when you look up a key that does not exist with square brackets.
Record
One dictionary describing one thing, such as one user, with named fields.
JSON
JavaScript Object Notation: a text format for sending data between systems, which maps directly onto Python lists and dictionaries.
Mutable
Able to be changed in place. Lists and dictionaries are mutable; strings and numbers are not.

3b. Handling errors with try and except

When something goes wrong while a program runs, Python raises an exception, an object describing the error. If nothing handles it, the program stops and shows a traceback.

Part 5, section 8 of 8

Summary and self-assessment

Key points

  • Open files with with open(path, mode, encoding="utf-8") as file: so they are always closed.
  • Mode "r" reads, "w" replaces the whole file, and "a" adds to the end.
  • Lines read from a file end with "\n"; strip() removes it.
  • try runs risky code; except SomeError: handles that specific error; else runs only if nothing went wrong.
  • Keep try blocks small, and catch only the errors you expect.
  • raise ValueError("message") lets your own functions report bad input.
  • Robust programs skip or report bad data, with line numbers, instead of crashing.

Key words

Mode
How a file is opened: for reading ("r"), writing ("w") or appending ("a").
Encoding
The rule for turning characters into bytes in a file. Use UTF-8, which handles every language and symbol.
Exception
An object Python raises when something goes wrong while a program runs, such as ValueError.
Raise
To signal an exception, either automatically when an error happens or deliberately with raise.
Handle
To catch an exception with except and respond to it, so the program does not crash.
CSV
Comma-separated values: a text format for tables, with one row per line.
Persistence
Saving data, for example to a file, so that it survives after the program ends.
Robust
Able to cope with bad input and unexpected situations without failing.
